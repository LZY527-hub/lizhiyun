什么是 CSS 变量？

CSS 变量（又称自定义属性）允许你定义可重复使用的值，通过 var() 函数引用。在 :root 中定义全局变量，整个页面都可以使用。

/* 定义变量 */ :root { --primary-color: #3498db; --spacing: 20px; } /* 使用变量 */ .card { color: var(--primary-color); padding: var(--spacing); }

优势

使用 CSS 变量可以轻松实现主题切换、统一设计风格，并减少重复代码。修改变量值即可全局更新样式。

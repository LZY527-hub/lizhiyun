CSS · Length Units

Web 前端的长度单位

CSS 长度由「数值 + 单位」组成（0 可省略单位）。单位分为两大类： 绝对单位固定不变，相对单位则随父元素、根元素或视口尺寸而缩放。

一、绝对单位

以物理尺寸或像素为基准，不随环境变化。屏幕上 1in 固定等于 96px。

px

像素，最常用的单位。1in = 96px。

in

英寸。1in = 2.54cm = 96px。

cm

厘米。1cm ≈ 37.8px。

mm

毫米。1mm = 0.1cm ≈ 3.78px。

pt

磅，印刷单位。1pt = 1/72in ≈ 1.333px。

pc

派卡。1pc = 12pt = 16px。

Q

1/4 毫米。1Q = 1/40cm ≈ 0.945px。

二、相对单位

相对于参照物计算，是响应式布局的核心。

em

相对当前元素（或父元素）的 font-size。会逐层叠加。

rem

相对根元素 html 的 font-size，始终以根字号为基准。

%

相对父元素同属性数值的百分比。

vw / vh

视口宽度 / 高度的 1%。100vw 即整个视口宽。

vmin / vmax

视口宽高中较小 / 较大者的 1%。

ex / ch

小写 x 的高度 / 字符 “0” 的宽度。

lh / rlh

相对元素 / 根元素的行高。

三、px / rem / em 对比

拖动滑块修改根元素 font-size，观察三种单位的缩放差异：px 固定不变，rem 与 em 随之变化。

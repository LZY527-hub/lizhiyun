TIMER DEMO

JavaScript 两种定时器

setTimeout 只执行一次，setInterval 每隔固定时间重复执行，可点击按钮实时体验

setTimeout 延时执行一次

等待指定的毫秒数后执行一次回调函数，执行完成后不会重复。

5 秒后执行

尚未开始

var lzy_id = setTimeout(function () {
    console.log("时间到");
}, 5000);

// 取消定时器
clearTimeout(lzy_id);
setInterval 周期性重复执行

每隔指定的毫秒数执行一次回调函数，直到调用 clearInterval 停止。

00:00:00

运行中：每隔 1 秒执行一次

已执行 0 次

var lzy_id = setInterval(function () {
    console.log("每隔 1 秒执行");
}, 1000);

// 停止定时器
clearInterval(lzy_id);

两种定时器对比

方法 执行次数 清除方法 典型用途
setTimeout 只执行一次 clearTimeout() 延时提示、延迟执行某个操作
setInterval 每隔一段时间重复执行 clearInterval() 时钟、倒计时、轮播图自动切换

# 项目规则

## 命名规范
- 所有 JavaScript 变量名必须以 `lzy_` 开头，例如：`lzy_userName`
- 所有 CSS 类名必须以 `lzy_` 开头，例如：`.lzy_container`
- 所有 HTML id 名必须以 `lzy_` 开头，例如：`id="lzy_submitBtn"`

## HTML 注释要求
- 所有 HTML 页面必须包含以下注释（日期和功能名称按页面实际填写）：

```html
<!-- 姓名：李知芸  日期：YYYY-MM-DD  功能名称：XXX -->
```

## 技术要求
- 只使用原生 HTML、CSS 和 JavaScript 实现，不使用任何框架
- 不使用第三方库和 CDN，所有资源本地化
- 图标统一使用 `font` 目录下的 iconfont 图标
- 获取服务器端数据必须使用 `fetch` API
